RainyDay Café Employability Portfolio
======================================

Files:
- index.html
- style.css
- script.js
- miraj-profile.png
- attendance-evidence.png
- linkedin-evidence.png
- gantt-chart.png

IMPORTANT:
All files are intentionally in the same folder.
The HTML uses direct filenames such as:
    <img src="miraj-profile.png">
It does NOT use an images/ folder.

GitHub Pages:
1. Create a repository.
2. Upload every file above into the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select the main branch and /(root), then Save.
